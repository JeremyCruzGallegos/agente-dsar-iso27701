# Estado del proyecto

- Corpus modelado en PostgreSQL mediante fuentes, disposiciones y relaciones.
- Recuperación directa de fuentes activas y disposiciones verificadas.
- API DPO para registrar fuentes, agregar disposiciones y aprobarlas.
- Chat con Ollama, historial, citas validadas y fallback sin invenciones.
- Skill de análisis normativo basada en registros de la base.
- Módulo DSAR, auditoría, retención, rectificación y anonimización conservados.
- PDF, TXT, Markdown, SentenceTransformers y FAISS retirados del flujo del agente.

La base normativa se entrega vacía deliberadamente: el equipo debe cargar únicamente transcripciones
verificadas y autorizadas. El resultado sigue siendo académico y requiere revisión humana.
