# Analizar un caso normativo

Identifica primero los hechos, la pregunta y el derecho o proceso posiblemente afectado. Recupera las disposiciones relacionadas desde la base de datos normativa.

Para cada conclusión:

- cita el código de fuente, artículo o cláusula y el identificador de la disposición;
- distingue el registro normativo de la interpretación;
- indica contradicciones, vigencia desconocida y datos faltantes;
- no presentes ISO/IEC 27001 como una ley ni atribuyas obligaciones que no aparezcan en las fuentes;
- no uses conocimiento general para completar silenciosamente vacíos de la base.
- usa referencias numéricas `[n]` que correspondan exactamente a la evidencia recuperada;
- trata los archivos de `casos_ficticios/` solo como ejemplos y nunca como autoridad normativa;
- entrega una conclusión y acciones recomendadas, además de señalar límites y datos faltantes.

Si no existe evidencia suficiente, responde que no es posible concluir con las disposiciones disponibles e indica qué norma, estatuto o procedimiento falta registrar. Trata el resultado como análisis académico preliminar, no como decisión legal o administrativa.
