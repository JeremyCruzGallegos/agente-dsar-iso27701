# Analizar un caso normativo

Identifica primero los hechos, la pregunta y el derecho o proceso posiblemente afectado. Recupera las disposiciones relacionadas desde la base documental local.

Para cada conclusión:

- cita el archivo y, cuando exista, la sección Markdown;
- distingue el texto documental de la interpretación;
- indica contradicciones, vigencia desconocida y datos faltantes;
- no presentes ISO/IEC 27001 como una ley ni atribuyas obligaciones que no aparezcan en las fuentes;
- no uses conocimiento general para completar silenciosamente vacíos documentales.

Si no existe evidencia suficiente, responde que no es posible concluir con la documentación disponible e indica qué tipo de norma, estatuto o procedimiento falta. Trata el resultado como análisis académico preliminar, no como decisión legal o administrativa.
